# A tool for Homebrewery monster stat block generation

1. Copy a statblock from https://www.dndbeyond.com or https://www.aidedd.org/dnd-filters/monsters.php 
2. Paste the plain text statblock into the *monster_text.txt* file.
3. Run Monster_to_homebrewery.py to convert it into a Homebrewery format.
4. Copy the Homebrewery statblock fomr *output_homebrewery.txt*
